## 8つの目的を現在のアプリで行うとき

起点はガイドを完了しロックを解除した当月のホーム。タップ数は実装からの最短推計で、スクロール・文字キーの数は含めず、入力欄へのフォーカスは1回に数える。「経路なし」には所要時間やタップ数を付けない。

|---|---|---|

## 金額の意味と照合結果

- `computeMonthCashFlow` と `computeMonthMetrics` は取引配列を月ごとに索引化し、配列参照に対して月集計を再利用する。家計収支の支出は購入額 `tx.amount`。振替元本は収支の対象外で、振込・プラットフォーム・為替の手数料は合算して「振替・振込手数料」になる。立替・その回収も家計収支から外す。カード利用時の支出を引落時に二重計上しない。 [addCashFlow](../../packages/core/src/utils/metrics.ts#L38)・[getTransferTotalFees](../../packages/core/src/utils/format.ts#L103)・[isOwnFlow](../../packages/core/src/utils/advances.ts)
- 残高は口座別の開始残高から計算する。入金は源泉徴収後、支払いはポイント充当後、振替は元口座から実出金＋手数料を引き、先口座に元本を加える。ホームの現在残高は未来日を除外する一方、月の収支はその月に記帳した未来日も含み得る。「お金の出入り」を追加する際は各月の購入額と、現金がいつどれだけ減ったかを明記した上で表現する。 [computeAccountBalances](../../packages/core/src/store/finance.ts#L36)・[getEffectiveOutflow](../../packages/core/src/utils/format.ts#L96)・[useCurrentBalances](../../apps/mobile/src/lib/currentBalances.ts)
- **使ったポイント**は支出・カードへの支払いで0円から取引総額まで登録でき、行に実支払額を表示する。**ためたポイント**に関しては、収入カテゴリ「雑収入・ポイント・ギフト」を手入力でき、別の Vite 版では受取方法「ポイント・電子残高付与」も選べる。Expo 版の支出に付与されたポイント数、サービス別の保有残高、有効期限、利用による専用残高の減算を対応機能とは数えない。ポイント収入を現金口座に登録すると、その口座の残高も増える。 [AddScreen の条件](../../apps/mobile/src/app/add.tsx#L103)・[受取方法とカテゴリ](../../packages/core/src/data/categories.ts#L41)・[Vite 版の受取方法](../../src/components/TransactionModal.tsx#L1506)・[TxRow](../../apps/mobile/src/ui/TxRow.tsx#L34)

**再現できた集計差。** 架空の銀行Aを10,000円、銀行Bを0円とし、同じ月に食費1,000円（200円ポイント利用）、AからBへの振替1,000円（手数料100円）、Aでの食費立替300円と全額回収を登録するデータで共通関数を実行した。家計収入0円、支出1,100円、収支−1,100円、残高はA 8,100円、B 1,000円。ホームとカテゴリ合計では購入と現金移動の差が保たれる。手数料付き振替は共通データのテスト入力で、現行Expoの振替フォームに手数料を直接入力する欄は見つからない。 [会計処理](../../packages/core/src/store/finance.ts#L36)・[支出入力の保存項目](../../apps/mobile/src/app/add.tsx#L198)

同じデータにカテゴリ詳細画面の抽出式を適用すると、分析一覧の手数料100円に対して詳細0円、食費一覧1,000円に対して詳細1,300円となった。詳細は取引の生の `categoryId` と額面のみで絞り・合計するため、合成項目 `transfer_fee` と立替除外を再現しない。金融UXの優先改修にする。内訳から明細へ渡す値を共通の「このカテゴリに寄与する金額」に統一し、手数料行で振替元本を支出表示しないことを受け入れ条件にする。[一覧から詳細への遷移](../../apps/mobile/src/app/%28tabs%29/analytics/index.tsx#L79)・[CategoryMonth](../../apps/mobile/src/app/%28tabs%29/analytics/category.tsx#L23)・[computeMonthMetrics](../../packages/core/src/utils/metrics.ts#L79)
