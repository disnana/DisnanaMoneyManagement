# マネーちゃん Android 家計簿・資産管理の設計

2026年11月22日。現行Expo版を土台に、「今いくらあるか」「なぜ今月この額になったか」「この買い物はもう記録したか」に順番に答えられる構成を提案する。先に直したいのは、分析の内訳から明細を開くと金額が変わる問題。見出しやカードの形を調整するだけでは解消できない。

## 現行から引き継ぐもの

中央の＋は1回で支出入力に進む。カテゴリ・口座・日付には初期値があり、右上と下部のどちらでも登録できる。グループによる家計の切替、ポイントを使った支出、カードの見込請求・確定・支払、貯金目標、予算、月別検索までつながっている。通信がなくても端末に書き込め、保存が成功してから画面に反映する。この日常動作とマネーちゃんのキャラクターを新機能の基盤にする。[現行コードとテストの調査](current-implementation.md)

Android・iOSの本体はExpo SDK 58／React Native 0.88。金融ロジックは共通のTypeScriptで、Androidの主な保存先はSQLite。Webは別のViteアプリとExpo Webの導線があり、FlutterとKotlin/Composeには別ブランチの試作がある。今回はExpoを継続し、日本語OCRのようなOS機能だけAndroid開発ビルドで検証する。現行のiPhoneの画面構成は比較の基準にする。[実装範囲](current-implementation.md)・[Android固有の設計条件](revolut-android.md)

## 画面の読み順

- **ホーム・口座**では家計グループと基準日を見て、口座名から右端の残高へ読み進み、直下の合計で照合する。通帳のように列をそろえ、余白と細い境界で「次の作業」に移る場所を示す。年月を変えても今日の残高と選択月の収支を混同させない。
- **家計簿・分析**では直近の取引にすぐ届くようにし、日が替わる境目、手数料・ポイントのある行だけを詳しくする。購入額・実支払・カテゴリへの寄与を選択した文脈に合わせて表示し、行から元の記録を開けるようにする。
- **入力・AI確認**では通常の＋から手入力を続けられる。撮影を選んだ人にだけ、店・日・合計と「品目別」を表示する。エラー時は直した内容と手入力への道を残す。タブや同じ形のカードを追加し続ける必要はない。
