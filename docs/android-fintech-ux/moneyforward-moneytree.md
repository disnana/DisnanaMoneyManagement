# マネーフォワード ME と Moneytree の残高・明細設計

2026年11月22日、日本向け個人版を調査。Google Play の掲載画像を目視し、公式ヘルプの Android 手順と照合した。ストア画像は掲載時のデザイン例、ヘルプは提供元が説明する操作である。認証済みアカウントでの操作時間、アニメーション、実際の戻り先、審査中の版は未検証。マネーフォワード ME の資産画面には11月24日以降の刷新予定があり、下記は11月22日に提供元が案内していた操作に限る。[マネーフォワード公式](https://moneyforward.com/)・[11月24日の事前告知](https://support.me.moneyforward.com/hc/ja/articles/64412495514521)・[Moneytree 個人向け公式サイト](https://getmoneytree.com/jp/app/about)

## 公開画面と公式仕様から分かったこと

| 観点 | マネーフォワード ME | Moneytree |
| --- | --- | --- |
| 利用者が最初に見る金額 | ホームには資産総額と集計期間の家計簿がある。公式が定義する「資産総額」は各資産の合計で、負債を差し引かない。負債を引いた額の確認先には Web のバランスシートを案内している。[ホーム](https://support.me.moneyforward.com/hc/ja/articles/24226189541401)・[資産総額の定義](https://support.me.moneyforward.com/hc/ja/articles/4407283942681) | Android 1.39.0 以降のインサイトでは「純資産」が資産から負債を引いた額を表す。詳細は推移の下に資産・負債の小計と金融機関別の金額を置く。金融機関を選ぶとその残高推移と取引一覧を開ける。[11月1日版の公式FAQ](https://help.getmoneytree.com/ja/articles/17765252) |
| 口座とカードの読み分け | Play掲載画像では複数の銀行の残高をカード別に右寄せし、その下のカード会社にはカードの金額を表示。ヘルプは確定引落額と引落後の銀行残高、カード利用残高を別の目的として説明する。証券にも対応する。[Android掲載画像](https://play.google.com/store/apps/details?hl=ja&id=com.moneyforward.android.app)・[口座・資産](https://support.me.moneyforward.com/hc/ja/articles/4407283942681) | 掲載画像の橙色の残高画面は、全体額の下に銀行・カード・電子マネー・証券を並べる。カード残高は未確定利用も含み得るため、今月の請求額とは値が違う。銀行と連動するデビットカードは残高の二重表示を避ける仕様。[Android掲載画像](https://play.google.com/store/apps/details?hl=ja&id=jp.moneytree.moneytree)・[カード残高](https://help.getmoneytree.com/ja/articles/407675)・[デビットカード](https://help.getmoneytree.com/ja/articles/5902834) |

## Androidで公開されている8つの操作

数値は、記載した起点からボタン・項目・キーボードの確定を選ぶ最小回数。文字入力、スクロール、読取待ち、初回権限、金融機関側認証は含めない。異なる起点同士で速度の優劣は判断できない。

| 目的 | マネーフォワード ME | Moneytree |
| --- | --- | --- |
| 1. 起動後に資産を知る | 認証後ホームで資産欄が展開済みなら追加0回。折りたたみ時は展開1回。ここで読めるのは資産総額。[ホームの表示](https://support.me.moneyforward.com/hc/ja/articles/24226189541401) | 下部メニューからインサイトを選ぶ1回で「純資産」の概要、さらに1回で資産・負債の小計。端末の起動直後のタブは未確認。[インサイト](https://help.getmoneytree.com/ja/articles/17765252) |
| 2. 今月の支出を見る | ホームの今月の家計簿が表示済みなら0回。カテゴリを見るには下部の「家計簿」へ1回。ユーザー設定で集計開始日が変わる。[ホーム](https://support.me.moneyforward.com/hc/ja/articles/24226189541401)・[家計簿](https://support.me.moneyforward.com/hc/ja/articles/4406430145049) | インサイトを選ぶ1回で当期支出の棒グラフ、支出を選ぶとさらに1回で取引先・日付・金額と支払方法別の割合を確認できる。[支出の表示](https://help.getmoneytree.com/ja/articles/17765252) |
| 3. 銀行を追加・管理する | 下部の口座から追加、銀行の種類、対象行の順に選ぶ。公式の三井住友銀行の例では外部ブラウザに移るまで4回。登録完了までの操作は銀行により異なる。[Androidの口座登録例](https://support.me.moneyforward.com/hc/ja/articles/13480029279897) | Android手順は右上のメニューから連携設定を開き、金庫の追加、対象の金融機関を選ぶまで4回。iOSでは入口が異なる。解約時には同期を停止して明細を残すアーカイブもある。[金融サービス登録](https://help.getmoneytree.com/ja/articles/407685)・[アーカイブと削除](https://help.getmoneytree.com/ja/articles/3702089) |
| 4. レシートを撮影して登録する | ホームまたは入出金から追加、レシート読取、撮影、内容を確認して保存。修正も方式変更も不要なら最短4回。[Androidの撮影手順](https://support.me.moneyforward.com/hc/ja/articles/4406223500697) | Androidの公式例は既存の取引行を開き、添付、画像の取得方法を選ぶところで3回。その先の撮影・保存までの総数は未確認。Workのレシート画像と取得明細の照合は有料機能として掲載されている。[Androidの添付](https://help.getmoneytree.com/ja/articles/3689720)・[Playのプラン説明](https://play.google.com/store/apps/details?hl=ja&id=jp.moneytree.moneytree) |
| 5. 読み取った商品情報を修正する | 確認中に該当の行を1回選んで修正できる。編集完了までの回数は項目による。公式の撮影手順は読取方式をAIとは特定していない。[Androidの読取結果](https://support.me.moneyforward.com/hc/ja/articles/4406223500697) | 確認できたのは取引のカテゴリ変更と添付画像から作る取引の日付・カテゴリの確認。レシート内の商品名・単価の個別修正は未確認。[カテゴリ修正](https://help.getmoneytree.com/ja/articles/407673)・[Androidの添付](https://help.getmoneytree.com/ja/articles/3689720) |
| 6. 一括記録と品目別を選ぶ | 読取後の店舗表示と品目表示のうち、表示中の方式が保存対象。もう一方の方式を選んで保存する場合は確認画面から最短2回。両方式を同時に保存しない。[保存方式](https://support.me.moneyforward.com/hc/ja/articles/4406223500697) | 公式のAndroid添付手順では登録済み明細への関連付けと新規取引の作成を選ぶ。品目単位と合計単位を切り替える記載は確認できなかった。[取引への添付](https://help.getmoneytree.com/ja/articles/3689720) |
| 7. カードと銀行の二重計上を解く | 下部の入出金、銀行の引落明細、振替への変更、該当カード、保存の5操作。買い物と銀行引落の双方が残り、引落をもう一度支出にしない。[Androidのカード引落手順](https://support.me.moneyforward.com/hc/ja/articles/4409270669209) | 銀行引落の一覧から、その行と「カード返済」を選ぶ最短2回。候補になければ親分類を開く追加操作が必要。カード利用履歴と同日に同額の買い物2件を自動統合する手順ではない。[カードと銀行の重複処理](https://help.getmoneytree.com/ja/articles/407699) |
| 8. 過去の取引を探して直す | 下部の入出金、検索、文字入力後の確定で検索結果まで3回。手入力の結果を開いて直し保存できる。専用ヘルプの検索上限は直近5,000件。取得原文と手入力とでは編集できる項目が異なる。[検索](https://support.me.moneyforward.com/hc/ja/articles/8406759284377)・[手入力の修正](https://support.me.moneyforward.com/hc/ja/articles/4406429556761) | 口座残高画面で全資産、検索欄を選ぶ2回＋文字入力で全明細を絞れる。1口座だけなら種類、口座、検索欄。検索には明細名・金額・カテゴリが使え、結果行からカテゴリを変更できる。[明細検索](https://help.getmoneytree.com/ja/articles/8286596)・[カテゴリ変更](https://help.getmoneytree.com/ja/articles/407673) |

## マネーちゃんへの設計判断

1. **ホームでは金額の意味を名前で伝える。** 現行のホームは選択家計に含まれる全口座の符号付き残高を合算して「現在の総資産」と表示する。口座間の振替やカード支払いで富が増減したと誤読しやすい。提案は、既存集計を使い、内訳に「口座残高の合計」「カード未払い」「差引後の純資産」を同じ対象範囲・基準日で表示すること。カードに過入金がある場合、銀行口座がマイナスの場合、外貨、連動デビットの重複まで定義してから名称を変更する。折りたたんだ口座にも全件の合計を提示する。[現行ホーム](../../apps/mobile/src/app/(tabs)/home/index.tsx)・[残高の基準日](../../apps/mobile/src/lib/currentBalances.ts)・[MFの定義](https://support.me.moneyforward.com/hc/ja/articles/4407283942681)・[Moneytreeの定義](https://help.getmoneytree.com/ja/articles/17765252)
2. **間違いを見つけた明細をその場で直せるようにする。** 元の摘要、取り込んだ経路、日付、支払元を明細詳細に残し、表示名と費目は修正可能にする。カード利用と後日の銀行引落は別の事象であり、引落は負債を減らす。二つの購入記録を照合する場合と、返済として扱う場合で操作名を変える。確定前後の月支出と口座残高をテストし、一致理由の説明と解除を用意する。[MFの原本](https://support.me.moneyforward.com/hc/ja/articles/24478005732889)・[Moneytreeの返済分類](https://help.getmoneytree.com/ja/articles/407699)
3. **レシート確認では保存結果を先に知らせる。** 撮影後、日付・店名・請求合計を確認し、必要な人が品目を開く。保存操作のラベルに「合計1件で記録」「品目3件で記録」のように選択結果を出す。既存明細に添付したときは支出記録数を増やさない。品目合計に値引き・税・端数を足して請求額と合わない場合は差額を提示し、登録途中で戻ったときも訂正内容を保持する。取得済み明細を除外して品目を一行ずつ再入力する操作は、家計簿と口座残高をずらしやすい。[MFの保存方式](https://support.me.moneyforward.com/hc/ja/articles/4406223500697)・[一括決済を分ける手順](https://support.me.moneyforward.com/hc/ja/articles/900004381363)・[Moneytreeの添付経路](https://help.getmoneytree.com/ja/articles/3689720)
4. **分析は「なぜこの額か」をたどれる形にする。** 同じ月・家計グループ・カテゴリのまま支出から明細、編集後に元の集計へ戻る。日々見る口座は残高を右に揃えた行、資産構成は小計、支出グラフには全体額と選択中の費目額を併記する。全幅を口座ごとのブランド色で塗ることや、すべての分析を独立したカードとしてホームに並べることは、必要な残高・支出を見つけるまでのスクロールを増やす。色覚・文字拡大への対応には期間・分類・金額をテキストでも残す。[MFの掲載画面](https://play.google.com/store/apps/details?hl=ja&id=com.moneyforward.android.app)・[Moneytreeの支出詳細](https://help.getmoneytree.com/ja/articles/17765252)
