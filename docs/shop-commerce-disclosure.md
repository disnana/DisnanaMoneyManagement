# 特定商取引法に基づく表記の公開原稿

本番販売の開始前に確定する原稿です。現在のWebショップはStripeのテスト決済のみを受け付け、実際の代金は請求しません。以下の表には、確定した販売条件と実際に対応できる窓口を記載します。試験用の商品設定は、本番の販売価格や有効期限を示すものではありません。

| 表示項目 | 公開時に記載する内容 |
| --- | --- |
| 販売事業者 | 個人の氏名または登記上の法人名。法人がWebで広告する場合は代表者または通信販売業務責任者の氏名も記載する |
| 所在地・電話番号 | 実際の住所と、消費者からの連絡に対応できる電話番号 |
| メール窓口 | `support@disnana.com`。購入・付与・返金を受け付ける運用を確認する |
| 販売価格と数量 | パックごとの税込総額と付与されるクレジット数。有効期限および起算日 |
| 代金以外に必要な費用 | 該当する手数料や利用者が負担する通信料等。該当する費用を確認して記載する |
| 支払方法と時期 | 本番の決済手段と、決済が確定する時点 |
| 提供時期 | 決済成立を確認した後、購入に使用したアカウントにクレジットが反映される時期。異常時の窓口と照会に必要な情報 |
| 申込みの撤回・契約解除・返金 | 確定した取消・返金の条件と手続、受付期限、費用負担の有無。重複決済、付与の不備その他の事業者側の債務不履行と、購入者都合を分けて記載する。適用法令に基づく権利を制限しない |
| 利用条件と制限 | 対応するAndroidのバージョンや端末、利用できる機能、アカウントの条件、適用される購入数量・期限・申込期間の制限 |

通信販売の広告と最終確認画面は両方確認します。最終確認画面では、注文確定前にパックと数量、価格・追加費用、支払方法と時期、提供時期、申込期間の定めがあればその内容、撤回・解除の条件を確認できるようにし、内容を訂正できるようにします。Stripe Checkoutで実際に表示される項目を本番設定で照合します。 [消費者庁の通信販売ガイド](https://www.no-trouble.caa.go.jp/what/mailorder/) · [消費者庁の最終確認画面資料](https://www.no-trouble.caa.go.jp/pdf/20240315ac01.pdf)

広告上の事業者情報の一部省略を検討する場合は、開示を請求できる旨を広告に表示し、申込みの判断に間に合うよう実際に開示できる体制を確認します。省略できる項目と要件は消費者庁の案内に従います。 [消費者庁の広告表示の省略条件](https://www.no-trouble.caa.go.jp/what/mailorder/)

購入型クレジットが前払式支払手段に該当するかは、使途、使用期限、発行方法と残高の管理方法を確認してから判断します。販売開始前に、適用除外、届出・登録、表示、払戻しの要否を所管の財務局等に確認します。有効期限と返金方針はその確認を踏まえて確定します。 [資金決済法](https://laws.e-gov.go.jp/law/421AC0000000059) · [金融庁の前払式支払手段案内](https://www.fsa.go.jp/news/27/sonota/20151214-2.html)

解析の公開前に、アプリに表示するサーバー側の結果取得期間、外部解析の委託先とデータ取扱い、画像の削除の実測結果を確認します。現在の実装候補はOpenAI APIです。運営者側の削除と、API側の保存期間や例外を整理し、国外で個人データが処理される場合は必要な情報提供、同意または相当措置を確認します。 [個人情報保護委員会の外国第三者提供ガイドライン](https://www.ppc.go.jp/personalinfo/legal/guidelines_offshore/) · [OpenAI APIのデータ管理](https://developers.openai.com/api/docs/guides/your-data)
